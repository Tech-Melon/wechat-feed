# 发布清单

把这个项目整理好发给其他人时，按下面的顺序过一遍。

## 1. 先定下来的事

- **许可证**：项目根目录还没有 `LICENSE`。自用小圈子分享可以不放；想公开发布，先选一个（例如 MIT），并在 README 里写明。
- **WeChatDataAnalysis 的关系**：本项目不包含、不修改 WDA 的代码，只在第一次通过它的本地接口取库密钥。发布时只放 WDA 的链接，让用户自己去下载开源版，不要把 WDA 的安装包打进来。
- **合规提醒**：读取的是用户自己电脑上、自己账号已经收到的消息。在说明里保留「只读本机、不上传聊天内容」这一条，不要加任何读取别人设备或远程转发聊天的功能。
- **发布渠道**：
  - 只发给熟人：发压缩包即可（见第 4 步）；
  - 公开：建一个代码仓库，`data/`、`dist/` 已在 `.gitignore` 里；
  - 上架 Chrome 网上应用店：需要开发者账号，并且要把 `host_permissions` 里的 `*://*/*` 说清楚用途（用户自己加入白名单的网站上显示浮窗）。不上架时，用户用「加载已解压的扩展程序」安装。

## 2. 发布前检查

```powershell
uv run pytest -q
uv run ruff check src tests scripts
uv run ruff format --check src tests scripts
```

手动按 README 末尾的「插件自测清单」过一遍，尤其是：

- gmgn 关注页亮色 / 暗色两种主题下卡片都清楚；
- 关掉 WDA 后 `wechat-feed.cmd status` 仍是 `direct`（也可以跑 `uv run python scripts/direct_e2e.py`）；
- 提示音三类（合约 / 星标用户 / 普通消息）共 9 段内置音频「试听」都能响。

## 3. 改版本号

四处保持一致，不一致时打包脚本会直接报错：

- `pyproject.toml` 的 `version`
- `extension/manifest.json` 的 `version`
- `src/wechat_feed/__init__.py` 的 `__version__`
- `web/index.html` 里 `feed.js?v=` 后面的版本（避免本地页用到浏览器缓存的旧文件）

## 4. 打包

```powershell
uv run python scripts/package.py
```

生成 `dist\wechat-feed-<版本>.zip`。脚本只收这些内容：

`src/`、`extension/`、`web/`、`scripts/`、`tests/`、`docs/`、`pyproject.toml`、`uv.lock`、`README.md`、`wechat-feed.cmd`、`.gitignore`

并且会：

- 去掉缓存文件和临时的 `_run_*.py`；
- 发现 `direct.json`、`settings.json`、`feed.db` 混进包里就直接报错停止；
- 压缩包里的路径统一用 `/`、文件名用 UTF-8，在别的电脑上解压中文文件名不会乱码。

**发出去之前自己解压检查一遍**：确认里面没有 `data` 文件夹，没有 `.venv`。

## 5. 在一台干净的电脑上试装

最好找一台没装过的电脑（或者新建一个 Windows 用户），完全照着 [使用指南](使用指南.md) 从头走一遍：

1. 装 uv → `setup` → 开 WDA → `install` → `status` 显示 `direct`；
2. 关掉 WDA，重启电脑，确认服务自己起来了；
3. 装插件，打开本地页、gmgn 插入、浮窗、语音提示各试一次。

哪一步卡住了，就把解决办法补进使用指南的「常见问题」。

## 6. 随包附上的说明

发给别人时附一段话，至少包括：

- 需要 Windows + 微信 4.x 桌面版 + Chrome / Edge；
- 第一次要用开源版 WeChatDataAnalysis 取密钥（附链接），之后可以关掉；
- 安装步骤看 `docs/使用指南.md`；
- 不要把自己的 `data` 文件夹发给别人。

## 不要发出去的东西

| 路径 | 内容 |
| --- | --- |
| `data/direct.json` | 微信库密钥 |
| `data/settings.json` | 你的群配置、备注、GMGN Key |
| `data/feed.db*` | 近 30 天的群消息缓存 |
| `data/avatars/`、`data/logs/` | 头像缓存、日志 |
| `.venv/` | 本机虚拟环境，对方要自己 `setup` |

## 已知限制（写进发布说明）

- 只支持 Windows。
- 微信版本更新可能改库结构；如果直读失败，服务会退回 WDA 模式，此时需要开着 WDA。
- 插件以「已解压的扩展程序」方式安装，Chrome 每次启动可能提示「停用开发者模式扩展程序」，点保留即可。
