# 技术瓜群流 · 使用指南

这份指南写给第一次拿到这个项目的人：从零装好、每天怎么开关、出问题怎么查。

## 它能做什么

把你电脑上微信 4.x **已经收到的群消息**实时显示出来：

- 本地网页 `http://127.0.0.1:8765/`；
- 在 gmgn.ai 的推特监控页里，把微信消息按时间插进推文流；
- 你指定的网页上的可拖拽浮窗；
- 群里出现合约地址（CA）、星标用户发言、普通新消息时，分别响不同的提示音；
- 群里的图片直接显示缩略图，点击可放大；高清版要微信已经下载到本机才会比缩略图更清晰。
- 「全部消息」和「只看 CA」各自勾选群来源，互不影响。本地页、gmgn 插入、网页浮窗各自再选全部或只看 CA，可以组合，例如 gmgn 只看 CA、浮窗看全部。
- 本地页有 **CA 发现榜**：谁先发现合约、喊单后涨了多少、谁胜率高。可关掉，关掉后不再为榜单打 GMGN。

它只读你本机的微信数据，不会替你发消息，也不会把聊天内容上传到任何服务器。

## 需要准备

| 项目 | 要求 |
| --- | --- |
| 系统 | Windows 10 / 11 |
| 微信 | 4.x 桌面版（适配 `4.1.13.65` 这一代），已登录，消息已同步到这台电脑 |
| 浏览器 | Chrome 或 Edge（Chromium 内核） |
| uv | Python 包管理工具，用来装依赖。不需要自己另装 Python |
| WeChatDataAnalysis | 开源版，**只用来取一次库密钥**。本项目不含 WDA。不要用文件名以 `advanced-` 开头的高级版 |
| 浏览器插件 | **不上架商店**。用开发者模式加载项目里的 `extension` 文件夹 |

## WeChatDataAnalysis 是干什么的

微信 4.x 桌面版把聊天记录存在本机加密库里。本仓库**不拷贝** [WeChatDataAnalysis](https://github.com/LifeArchiveProject/WeChatDataAnalysis)（下称 WDA）的源码；需要时请到它的 GitHub 自行下载开源版。WDA 负责算出库密钥，之后由本项目轻量只读盯库。细节见 [wda.md](wda.md)。

本服务第一次启动时，向你电脑上已经打开的 WDA 要一次密钥，写进 `data\direct.json`。之后：

- 本服务自己只读打开微信库，实时看新消息；
- **WDA 可以关掉**，不必一直开着；
- 本仓库不附带 WDA，请到它的 GitHub 自己下载开源版。

还需要再开 WDA 的时候：微信换了账号（`status` 变成 `wda`）、或者群图片一直是「[图片]」说明还没取过图片密钥。

安装 uv（在 PowerShell 里执行，装完**重新打开**命令行窗口）：

```powershell
powershell -ExecutionPolicy Bypass -c "irm https://astral.sh/uv/install.ps1 | iex"
```

## 第一次安装

1. **解压**项目到一个固定位置，例如 `D:\wechat-feed`。之后不要随意挪动这个文件夹（开机自启记的是绝对路径；挪了以后重新执行一次第 4 步即可）。
2. **装依赖**：在项目文件夹里打开命令行，执行：

   ```powershell
   .\wechat-feed.cmd setup
   ```

3. **取密钥**：打开 WeChatDataAnalysis，按它的提示完成解密，保持它开着。
4. **启动并设为开机自启**：

   ```powershell
   .\wechat-feed.cmd install
   ```

   看到「已在后台启动」后，执行 `.\wechat-feed.cmd status`，数据来源显示 `direct` 就说明密钥已经存好了。**这时就可以关掉 WeChatDataAnalysis**，以后都不需要它。
5. **装浏览器插件**（不上架商店，只能这样装）：
   1. 打开 `chrome://extensions`（Edge 是 `edge://extensions`）；
   2. 打开右上角「开发者模式」；
   3. 点「加载已解压的扩展程序」，选项目里的 `extension` 文件夹；
   4. 把插件图标固定到工具栏，点开弹窗，状态里不再提示「本地服务没连上」就成功了。
   5. Chrome 以后启动时如果提示「停用开发者模式扩展程序」，点「保留」。
6. **打开本地页面** `http://127.0.0.1:8765/`。用表单添加监控群（不添加就是全部群聊，私聊永远不会进来）。顶栏「全部消息 / 只看 CA」只改本地页。gmgn 插入和网页浮窗在通路二各自再选全部或只看 CA。两套群来源在「群聊选择管理」里勾，可同时多选，全选表示包括以后新加的监控群。每个监控群可以展开「成员」：默认监听全员，也可以改成只听部分人，并在成员列表里星标或屏蔽某人。卡片上的「不看此人」是全局屏蔽，所有群都不再显示他的发言。无论怎么勾显示规则，监控群的消息都会全盘入库，页面只按当前规则决定显示谁。

## 插件怎么用

点浏览器工具栏上的插件图标：

- **插入 gmgn 推特信息流**：打开后去 `https://gmgn.ai/follow`，微信消息会按时间插在推文之间，跟随 gmgn 的亮色 / 暗色主题。下面「该通路显示」可单独选全部消息或只看 CA。
- **白名单网页浮窗**：只在「浮窗白名单」里的网址右上角出现一个可拖拽、可缩放的消息面板，「收起」后缩成右下角的小按钮。默认只有 `https://gmgn.ai/follow?target=xTracker`。浮窗也有自己的全部 / 只看 CA，和 gmgn 插入、本地页互不影响。
  - 在弹窗的白名单框里每行写一个网址，点「保存白名单」；新加的网站要刷新页面。
  - 匹配规则：域名和路径要一致，白名单里写出的参数也要一致，网址多出来的参数不影响。例如写 `https://weibo.tech-melon.top/?mode=all`，那么 `?mode=all&x=1` 会显示，`?mode=star` 不会显示。
  - 白名单清空就哪里都不显示。
- 弹窗分三页：「显示」开关 gmgn 插入、浮窗（各带全部 / 只看 CA）和 **CA 发现榜**；「提示音」设置三类提示音，「设置」里是浮窗白名单和 GMGN Key。
- **卡片水印**：gmgn / 浮窗卡片只在簇顶底部固定为「𝕏 @0xTechMelon」，点开就是作者推特，不能改。同一人连续发言时，后面的气泡不再重复头像、昵称、群名和水印。
- **提示音**：分三类，各自勾选开关：
  - 合约（CA）：内置 1 中文语音「注意，群里有新合约」、内置 2 叮咚、内置 3 急促三连音；
  - 星标用户发言：内置 1 清亮钟声、内置 2 竖琴上行、内置 3 中文语音「星标用户发言了」；
  - 普通消息（仿微信）：内置 1 木琴叮咚、内置 2 气泡、内置 3 轻敲；
  - 每一类都可以选「自定义音频」，点「选择文件」加载 mp3 / wav / ogg（3 MB 以内）。如果选文件时弹窗自己关掉了，点弹窗里的「在新标签页打开这里」，在标签页里选；
  - 每类旁边有「试听」，音量三类共用；
  - 规则：一条消息只响一种，合约 > 星标用户 > 普通消息，前一类没开就往下找；同一条只响一次；1.5 秒内同级或更低级的不再响，更重要的可以插队；自己发的、超过 2 分钟的旧消息、被你屏蔽的群和屏蔽的人都不响。提示音跟「群聊选择管理」一致：只勾了「只看 CA」没勾「全部消息」的群，没有合约的普通消息不响（星标用户也一样，看不见的消息不响）。浏览器开着就会响，不需要停在某个网页上。
- **GMGN OpenAPI Key**（可选）：填了以后代币卡片会多出税率、安全检测、持有人等信息，排行榜空闲时也会用它刷喊单后的最高倍。Key 只保存在本机服务里。
- **CA 发现榜**：和本地页顶部的开关是同一项。关掉后空闲不再为榜单请求 GMGN，信息流里的市值补全不受影响。

卡片上可以：点名字或群名写备注、点 ☆ 星标某个人、点「不看此人」屏蔽这个人、点「不看此群」屏蔽这个群、点合约后面的「复制」。屏蔽的人和群会在本地页工具区出现红色「恢复」按钮。备注过的群名是蓝描边加粗胶囊。

## CA 从收到到完整显示

群里出现合约地址后，卡片会先出来，代币详情后到：

1. 本机微信库（direct）或 WeChatDataAnalysis 实时流读到一条群消息。
2. `normalize_message_event` 从正文、引用、标题里抽出 CA，生成卡片：`addresses` / `cas` 已有，`tokenCards` 为空。
3. 不在监控群的不入库。屏蔽群/人、群来源、只听部分成员都只过滤显示，已经入库的消息还在。
4. `hub.publish` 立刻通过 SSE `message` 推给本地页和插件；有 CA 时再补该发送者前后 3 句，SSE `patch` 一次。
5. 后台异步 `resolve_many`：裸 EVM 先打一次不带链的 GMGN `/v1/market/search`（官方用 `coins[].chain` 反查链）。只有这次没命中才补 bsc / eth / robinhood。search 已有链和市值（含 `mcp`）就直接用，不再打 token/info；缺市值时 info 与 security 并行。缓存 2 秒。429 冷却 8 秒，期间走 DexScreener 兜底。
6. 每查出一张代币卡就 `hub.patch(tokenCards)`，SSE `patch` 刷新卡片：代码芯片换成市值、税率、持有、logo。
7. 插件插入 gmgn 时，代币图走后台代理；失败显示字母头。

所以「有 CA 的消息」和「CA 详情齐」是两步。详情慢通常是 GMGN 限频或 search 未命中后的 Dex 兜底。

## CA 发现榜

本地页顶部一条入口，点「打开排行榜」进独立页。数据记在本机 `data/ca.db`，留 1 年。

**怎么记**

- **所有群首发**：监控里第一次出现这个合约。记下人、群、时间、当时市值。
- **本群首发**：这个群第一次出现（哪怕别的群早就发过）。
- 倍数相对「第一次喊到时的市值」。当前倍 = 现市值 / 那一口；最高倍 = 喊单**之后** K 线最高市值 / 那一口。不用 GMGN 给的历史总 ATH（那可能是喊单前就拉过的顶）。
- 卡片上本条就是第一次发出：金条「所有群首发 · 本群首发」。别的群先发过、这个群第一次：蓝条「本群首发」，并写清所有群是谁先发现的。

**怎么算胜**

以该用户自己第一次喊到这个 CA 时的市值为基准：**ATH ≥ 1.5 倍（涨幅 50%）算胜**。榜顶有绿标说明。得分是威尔逊下限 × 次数 × 平均倍数，用来压住「一单暴击」。

**用户页**

点榜上的人（或卡片上发现条的名字）看他喊过的每个 CA：喊单市值、当前倍、最高倍、链图标、日期。可按最新 / 最早 / 最高倍 / 当前倍 / 喊单市值排序，按今天 / 7 天 / 30 天和已胜 / 未到 50% 筛选。

**榜怎么更新、打几次 GMGN**

- 打开榜、新 CA 消息、空闲刷完一条，都会重算。拉榜本身读本机库，**0 次** OpenAPI。
- 实时新消息：search 定链和现价（权重 1）。已有链和市值就不再打 token/info。
- 后台刷新（排行榜开着时）是增量的：每个币记一条水位线，平时只从水位线拉到现在，通常 1 次 K 线（权重 3）。K 线只拉一遍，所有喊单人按各自喊单时间切片共用。
- 新喊单 60 秒后做一次首结算：只补它自己喊单时间附近的细粒度段（喊单 → 整点 1m，整点 → UTC 0 点 1h，之后 1d）。只认开盘不早于喊单前 60 秒的柱，跨过喊单的粗柱不算，开盘拉盘的顶不会记到喊单人头上。
- 喊单后最高只增不减：GMGN 偶尔回空列表或拉取失败，都不会把已有高点改小；失败时水位线不动，下次重拉。
- 每个币刷完一次就冻结：最后被喊 6 小时内冻结 15 分钟，3 天内 1 小时，更早 6 小时，之后才回到待刷队列。K 线是历史数据，冻结不会漏掉高点，只是榜单晚一点更新；要马上看可以在详情页手动刷新。超过 24 小时没人再喊、现市值低于 1.5 万的币**休眠**不刷；最后一次被喊超过 7 天的币**定格**，不再自动刷新。再被喊到都会自动恢复。
- 倍数口径同 Ave：最高倍数 = 喊单之后的最高市值 / 喊单市值，当前倍数 = 现市值 / 喊单市值。
- 胜：最高倍 ≥ 1.5；喊单不满 6 小时且还没到的记为**待定**，不进胜率分母。均倍按单条 20 倍封顶后平均。榜单可切全部 / 近 30 天 / 近 7 天。
- 限频：免费档每秒权重 5，本地按 1.2 秒窗口记账留 20% 余量，并按响应头校准。后台每个窗口都给实时留 2 点权重（后台上限约 2.5 权重/秒，稳态约 1.6），实时在跑就让开；429 时后台停 8 秒，实时退避 1 秒重试。关掉排行榜后后台刷新整段停掉。

**关掉**

本地页入口最左边的「排行榜」开关，或插件弹窗「显示」里的「CA 发现榜」。关掉后入口收起，文案变成「已关闭，不刷 GMGN」。

## 日常使用

所有命令都在项目文件夹里执行：

| 想做的事 | 命令 |
| --- | --- |
| 启动 | `.\wechat-feed.cmd start` |
| 关闭 | `.\wechat-feed.cmd stop` |
| 重启 | `.\wechat-feed.cmd restart` |
| 看状态 | `.\wechat-feed.cmd status` |
| 看日志 | `.\wechat-feed.cmd logs` |
| 开机自启 | `.\wechat-feed.cmd install` |
| 取消开机自启 | `.\wechat-feed.cmd uninstall` |

- **电脑重启后**：开了开机自启就什么都不用做，登录 Windows 后服务会在后台自己起来（没有窗口）。没开的话执行一次 `start`。
- **不想要后台常驻**：`uninstall` 取消自启，再 `stop`。需要时手动 `start`。
- **资源占用**：常驻约 100 MB 内存，空闲时 CPU 约占一个核的 1–2%。WeChatDataAnalysis 取完密钥后不用再开。
- 微信本身不需要一直开着，但只有微信在线时才会收到新消息。

## 更新到新版本

1. `.\wechat-feed.cmd stop`
2. 用新版本的文件覆盖项目文件夹，**保留 `data` 文件夹**（里面是你的配置、备注、密钥和消息缓存）。
3. `.\wechat-feed.cmd setup`
4. `.\wechat-feed.cmd start`
5. 到 `chrome://extensions` 里点插件的「重新加载」。

## 卸载

1. `.\wechat-feed.cmd uninstall`，再 `.\wechat-feed.cmd stop`；
2. 在 `chrome://extensions` 里移除插件；
3. 删除项目文件夹（`data` 里的密钥和聊天缓存会一起删掉）。

## 常见问题

**插件弹窗提示「本地服务没连上」**
执行 `status`。没在运行就 `start`；运行了还连不上，看 `logs`。

**`status` 里数据来源是 `wda`，或者一直提示连不上**
说明还没有直读密钥，或密钥失效了（例如微信换了账号）。打开 WeChatDataAnalysis 完成解密，等半分钟服务会自动重新取密钥，`status` 变成 `direct` 后再关掉它。

**`start` 提示 15 秒内没起来**
看 `logs`。最常见的是 8765 端口被占：可能你另开了一个前台的 `uv run wechat-feed`，关掉它再 `start`。

**gmgn 页面上没看到插入的卡片**
卡片按时间插在推文之间：如果最新几条推文都比最新的微信消息新，卡片会在下面一点的位置，往下滚就能看到。确认弹窗里「插入 gmgn 推特信息流」已勾选，并刷新页面。

**语音不响**
先点「试听」。试听也不响：检查系统音量和浏览器标签页是否被静音。试听正常但新消息不响：确认对应那一类的开关勾上了（合约提示要消息里真有合约地址，星标提示要先在卡片上给那个人点 ☆），且群没有被屏蔽。

**群图片只显示「[图片]」**
图片要用微信的图片密钥解开，服务会从 WeChatDataAnalysis 桌面版的本机配置里读一次。如果从来没用 WDA 解密过图片，打开 WDA 让它取一次图片密钥，然后 `restart` 服务。新收到的图片要等微信把缩略图下载完，一般几秒内就会出现。

**点开图片还是糊的**
卡片里是微信的缩略图。本服务只读电脑上已经有的文件，不会去微信服务器拉原图。高清 `_h` 通常要你在微信里点开过那张图才会下载；原图经常是 wxgf（HEVC），浏览器显示不了。先在微信里打开一次，再回来点放大。

**挪动了项目文件夹**
重新执行 `setup` 和 `install`。

## 隐私说明

- 服务只监听本机 `127.0.0.1`，局域网里的其他设备访问不到；普通网页也读不到群消息，只有这个浏览器插件可以。
- `data\direct.json` 是微信库密钥，拿到它就能读你全部聊天记录。**不要把 `data` 文件夹发给任何人。**
- 代币信息会用合约地址查询 DexScreener 和 GMGN，只发送合约地址，不发送聊天内容。
- `data\ca.db` 是一年内的 CA 发现和喊单记录，和 `direct.json` 一样不要外传。
